# DOT Olympiads Website

Upload the contents of this folder to the root of the `dot-olympiads` GitHub repository. Keep `index.html`, `syllabus.json`, and the entire `assets` folder together.

- `index.html` — responsive website
- `syllabus.json` — subject-wise syllabus data
- `assets/dot-logo.svg` — clean circular DOT Olympiads brand mark
- `assets/subjects/` — six subject badge images provided by DOT Olympiads

GitHub Pages URL: https://mukeshparankusam.github.io/dot-olympiads/

Note: institution form and result lookup are front-end placeholders; they require a secure backend before collecting/storing registrations or publishing results.
